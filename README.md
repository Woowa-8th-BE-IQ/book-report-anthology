# 덕후감

> 같은 책을 읽은 사람들은 무슨 생각을 했을까.

같은 책을 읽은 사람들이 독후감을 한 편씩 쓰고, 한 권의 전자책 문집으로 엮는 서비스예요.
**내 글을 내야 남의 글이 열려요.** 그래서 끝까지 쓰게 돼요.

**https://book-report-anthology.onrender.com**

우아한테크코스 6기 크루 45명이 함께 낸 『일단 나부터 리팩터링 합니다 1』에서 영감을 받았어요.

---

## 한눈에

```
문집 열기 ──▶ 초대 링크 공유 ──▶ 각자 독후감 쓰기 ──▶ 내 글 내기 ──▶ 남의 글이 열림
                                     │                                  │
                                     └── 모임방·꼬깃 서고에서 같이 놀기 ──┘
                                                                        ▼
                                                    마감 ──▶ EPUB·PDF 한 권 완성
```

| 이런 분께 | 이렇게 쓰면 돼요 |
| --- | --- |
| 독서 모임 운영자 | 문집을 열고 마감일·글감 질문을 정해요. 초대 링크를 단톡방에 붙여요. |
| 모임 사람 | 링크로 들어와 독후감을 써요. 내면 다른 사람 글이 열려요. |
| 같이 있고 싶은 사람 | 모임방에서 대화하고, 꼬깃 서고를 걸어 다니고, 펫을 바탕화면에 띄워 둬요. |

---

## 이렇게 써요

1. **문집을 열어요.** 책 제목과 마감일을 정하면 초대 링크가 나와요. 카톡방에 붙이면 초대 카드로 보여요.
2. **각자 독후감을 써요.** 200자부터 낼 수 있어요. 쓰는 동안 저절로 저장돼요.
3. **내 글을 내야 남의 글이 열려요.** 내기 전에는 책장에 제목과 분량만 보여요. 본문은 서버가 아예 보내지 않아요.
4. **마감하면 한 권이 돼요.** 목차·도서 소개·부록을 갖춘 EPUB과 인쇄용 A5 PDF를 받아요.

## 기능

### ✍️ 문집과 쓰기

- **초대 링크**로 참여, **개인 링크**로 어느 기기에서든 이어 쓰기
- **자동 저장**: 서버와 이 기기에 사본을 둬서 창을 닫아도 남아요
- **원문 밑줄 한 줄**: 한 편에 하나, 150자까지, 원서 출처가 자동으로 붙어요
- **제출 전 미리보기**: 책 한 쪽에 실릴 모습으로 봐요
- 엮은이: **글감 질문**(최대 3개), 도서 소개, 부록

### 📖 읽기

- 잠긴 카드가 **제출하는 순간 하나씩 열려요**
- 답글(책에는 안 실려요), 새 글·안 읽은 글 표시

### 📚 책 만들기

- 차례 순서 정하기, 내 글 책에서 빼기
- **EPUB 3**(epubcheck 통과)와 **A5 인쇄용 PDF**(부크크·교보 바로출판에 그대로 올리는 용도)
- 마음에 든 대화는 책 뒤 **"함께 나눈 이야기"**로 실려요
- **공개 소개 페이지**: 목차와 쓴 사람이 허락한 맛보기 한 편만 보여요

### 💬 모임방

- 꼬깃단 캐릭터로 책상에 둘러앉아 **실시간 대화**
- **`@닉네임`**, **`@모두`**로 부르기: 부른 사람의 펫만 크게 반응해요
- **책갈피**: 마음에 든 말에 꽂으면 책갈피 모음에 모이고, 꼬깃 서고 천장에 별이 늘어요
- **소식**: 누가 냈다, 내 글에 답글, 마감했다, 마감이 오늘·내일이다

### 🏛️ 꼬깃 서고 (3D)

문집마다 하나 있는, 걸어 다니는 **종이 디오라마 서고**예요. 모임방 대화를 같이 써요.

- **큰 서고**: 아치 창으로 드는 햇빛과 그림자, 펼친 책 조형물, 열람 테이블과 스탠드, 창가 벤치, 빈백
- **다락**: 왼쪽 계단으로 올라가요. 이불에 누우면 이불이 덮이고 스탠드가 어두워져요
- **옥상 정원**: 다락 문으로 가요. 해먹, 망원경, 책갈피 별자리, 그날의 날씨(맑음·비·눈)
- **앉기·눕기**: 의자에 앉으면 다리가 접히고 의자가 삐걱, 그 테이블 스탠드가 딸깍 켜져요
- **낮잠**: 가만히 45초면 꾸벅꾸벅, 150초면 잠들어요. 움직이면 번쩍 깨요
- **가까운 사람 말은 크게**, 먼 사람 말은 작고 흐리게 보여요
- **소리**: 시간대별 배경음, 꼬깃단마다 다른 발소리(러그 위는 먹먹하게), 의자·문·종 효과음
- WebGL이 안 되는 기기에서는 2D 서고로 열려요

| 하고 싶은 것 | 키 | 화면 |
| --- | --- | --- |
| 걷기 | `W` `A` `S` `D` / 방향키 | 바닥 누르기 |
| 달리기 | `Shift` 누른 채 걷기 | 달리기 단추 |
| 점프 | `Space` | 점프 단추 |
| 앉기·일어서기 | `Z` | 의자·방석 누르기 |
| 낮잠 | `N` | 낮잠 단추, 이불·해먹 누르기 |
| 인사 · 기지개 · 사락사락 | `E` · `Q` · `R` | 단추 |
| 둘러보기 | `[` `]` | 끌기, ⟲ ⟳ |
| 당기기·밀기 | | 휠, 두 손가락, ＋ － |
| 한마디 | `Enter` | 아래 입력칸 |

### 🐧 꼬깃단

종이를 접고 꾸겨 만든 덕후감의 여덟 친구예요. 모임방·펫·서고에서 내 캐릭터가 돼요.

| 이름 | 누구 | 직책 |
| --- | --- | --- |
| 뒤뚱 | 바위뛰기펭귄, 엮은 책을 안고 배달해요 | 덕후감 대표 |
| 느릿 | 달팽이, 책이 오길 목 빠지게 기다려요 | 인내심 전무 |
| 꽥이 | 오리, 책 지붕 아래서 비를 피해요 | 사내 BGM 이사 |
| 더듬 | 두더지, 밤이면 헤드램프를 켜고 책을 파요 | 야근 자처 본부장 |
| 개굴 | 개구리, 좋은 말을 혀로 콕 낚아요 | 명언 낚시 팀장 |
| 꾸벅 | 너구리, 졸면서도 끝까지 읽어요 | 근무 중 수면 대리 |
| 꼼지 | 책벌레, 한 줄씩 꼭꼭 씹어 읽어요 | 정독 연구원 |
| 따끔 | 고슴도치, 책 읽다 털이 몽실몽실해졌어요 | 프리허그 담당자 |

### 🖥️ 데스크톱 펫

내 꼬깃단이 바탕화면에 떠 있어요.

- 새 말·부름·소식이 **말풍선**으로 떠요. 누르면 대화창이 열려요
- 펫에서 **바로 답장**, 여러 문집 탭, 안 읽은 수
- 오른쪽 클릭 메뉴: **꼬깃 서고 가기**, 책갈피 모음, 캐릭터 바꾸기, 배경음, 걸음 효과
- 바탕화면을 산책하고, 새 버전이 나오면 **스스로 업데이트**해요

## 데스크톱 펫 설치

**맥**: 터미널에 붙여 넣으세요.

```bash
curl -fsSL https://book-report-anthology.onrender.com/pet/install.sh | bash
```

**윈도우**: PowerShell에 붙여 넣으세요.

```powershell
irm https://book-report-anthology.onrender.com/pet/install.ps1 | iex
```

켜지면 문집 화면의 **내 개인 링크**를 붙여 넣어요. 자세한 내용은 [펫 안내](desktop/README.md)에 있어요.

이미 깔려 있으면 껐다 켜기만 해도 새 버전을 받아요.

```bash
pkill -x BookReportPet; sleep 2; open /Applications/BookReportPet.app
```

## 개발

```bash
./gradlew bootRun     # http://localhost:8080
./gradlew test
```

Java 21이 필요해요. 로컬 데이터는 `./data/anthology.mv.db`(H2 파일)에 쌓여요.

```
src/main/java/com/iq/anthology
├── anthology  문집과 참여자
├── essay      독후감, 답글, 책장(읽기 규칙), 문집 소식 이벤트
├── room       모임방·꼬깃 서고 실시간(SSE), 꼬깃단, 부르기, 소식·마감 재촉
├── book       EPUB·PDF·표지
├── activity   퍼널 기록
├── support    오류, 글자 수·조사
└── web        컨트롤러와 화면 모델

src/main/resources/static/js
├── app.js            문집·모임방 화면
├── pet.js            데스크톱 펫 화면
├── library3d.js      꼬깃 서고 3D (three.js: 장소·길 찾기·종이 인형·카메라)
├── library.js        꼬깃 서고 2D (WebGL이 없을 때)
├── library-sound.js  서고 효과음(녹음 없이 합성)
└── ambience.js       배경음
desktop/              데스크톱 펫 (Electron)
```

## 배포

- **서버**: Render(Docker, 무료) + Neon(PostgreSQL, 무료). [배포 안내](docs/deploy.md)
- **펫**: `main`에 `desktop/`이 바뀌어 올라가면 GitHub Actions가 맥·윈도우 파일을 만들어 릴리스(`pet-v…`)에 올려요. 펫이 그걸 찾아 스스로 업데이트해요. 펫 화면 자체는 서버 페이지라 서버 배포만으로 바뀌어요.
