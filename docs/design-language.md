# 디자인 언어

"종이 위에 잉크로 쓴 문집"을 화면으로 옮긴다. 한 인디 북클럽 랜딩에서 받은 인상(종이 질감, 손글씨 표시, 테이프 카드, 회전하는 타이포 포스터)을 분위기와 효과 수준에서만 재해석했다. 로고·사진·문구는 모두 자체 제작이다.

## 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--paper` | `#F6F1E9` | 페이지 배경 |
| `--paper-deep` | `#EEE5D8` | 섹션 교차 배경 |
| `--card` | `#FFFDF8` | 카드·종이 |
| `--ink` | `#1A1208` | 본문 |
| `--ink-soft` | `#4A3020` | 보조 본문 |
| `--muted` | `#8A7660` | 캡션 |
| `--line` | `#D8C9B4` | 테두리 |
| `--tape` | `#C9B8A0` | 마스킹 테이프 |
| `--accent` | `#B8571A` | 버튼·강조 |
| `--accent-bright` | `#D2691E` | 손글씨 표시 |
| `--good` | `#4F6B3A` | 제출·완료 |

글꼴: 본문 SUIT, 독후감 본문·인용 Noto Serif KR, 손글씨 표시 Nanum Pen Script.

## 밤의 서재 (다크 모드)

- 기기 설정(`prefers-color-scheme`)을 따른다. 머리말의 달·해 단추로 고르면 `<html data-theme>`과 `localStorage.theme`에 남고, 그쪽이 이긴다.
- 같은 토큰 이름에 밤 값만 바꾼다: 종이 `#16110C`, 카드 `#211913`, 잉크 `#F1E7D8`, 강조 `#E38544`.
- 테마와 상관없이 밝아야 하는 글자(주황 단추, 나무 책상, 가림막 위)는 `--cream`, 가림막은 `--scrim`, 오류색은 `--danger`.
- 깜빡임을 막으려고 `<head>`의 첫 스크립트에서 저장된 테마를 먼저 건다.
- 펫은 컴퓨터의 다크 모드를 따른다(따로 단추 없음).

## 효과

| 효과 | 쓰는 곳 | 의미 |
| --- | --- | --- |
| 회전 타이포 포스터 | 랜딩 히어로 | 한 권을 둘러싼 여러 사람의 글. 작게 빠르게 돌다 천천히 자리 잡는다 |
| 글자 펼침(char-reveal) | 섹션·페이지 제목 | 글자가 접혀 있다 하나씩 펴진다 |
| 밑줄 늘이기(line-expand) | 제목 아래 짧은 오렌지 선 | 손으로 긋는 밑줄 |
| 손글씨 동그라미 | 단계 번호 | 펜으로 그리듯 stroke가 그려진다 |
| 테이프 카드 | 독후감 카드, 내 글, 폼 | 종이를 붙여 둔 문집 |
| 잠긴 카드 | 제출 전 남의 독후감 | 제목만 보이고 본문 자리는 흐린 줄 + "제출하면 열려요" |
| 점선 목차 | 원고·공개 소개 | `감자(김주하) ········ 제목`, 레퍼런스 문집의 목차 형식 |
| 도미노 뒤집기 | 로고 마크 hover | 책장이 넘어가는 느낌 |
| 하단 고정 CTA | 랜딩·문집 화면 | 지금 할 수 있는 한 가지 행동 |

숨겼다가 보여 주는 효과는 `<html class="js">`일 때만 건다. JS가 실패해도 내용은 보인다.
모든 애니메이션은 `prefers-reduced-motion: reduce`에서 끈다.
