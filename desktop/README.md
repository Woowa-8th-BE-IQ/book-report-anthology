# 덕후감 펫

모임방의 내 아바타가 바탕화면 위에 떠 있어요. 모임방에 새 말이 오면 머리 위로 말풍선이 떠요.

## 받기

[릴리스](https://github.com/Woowa-8th-BE-IQ/book-report-anthology/releases)에서 `pet-v…`를 열고 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 파일 |
| --- | --- |
| 맥 (M1 이후) | `book-report-pet-…-mac-arm64.zip` |
| 맥 (인텔) | `book-report-pet-…-mac-x64.zip` |
| 윈도우 | `book-report-pet-…-win-x64.exe` |

## 처음 실행할 때

서명하지 않은 앱이라 처음 한 번은 경고가 떠요.

- **맥**: zip을 풀어 나온 앱을 응용 프로그램 폴더로 옮겨요. 그다음 앱을 **우클릭 → 열기 → 열기**를 눌러요. 그래도 막히면 터미널에서 `xattr -cr /Applications/BookReportPet.app`를 한 번 실행해요.
- **윈도우**: "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.

앱이 열리면 문집 화면 아래 **내 개인 링크**를 붙여 넣어요. 그러면 연결돼요.

## 문집이 여러 개면

펫 대화창 위의 **＋** 를 눌러 새 문집을 열거나, 받은 초대 링크로 참여해요. 문집을 열면 초대 링크가 바로 떠서 복사해 보낼 수 있어요. 대화창 위에 문집 탭이 생기고, 말풍선에는 `[문집 이름]`이 붙어요.

## 쓰는 법

- 아바타를 **누르면** 작은 대화창이 열려요. 바로 답장할 수 있어요. 길게 쓰면 입력칸이 아래로 늘어나요.
- 대화창 위의 **키보드 단추**로 타자 소리를 켜고 꺼요.
- 대화창 위의 **헤드폰 단추**(또는 우클릭 → 배경음)로 배경음을 틀어요. 빗소리·호숫가·귀뚜라미·은은한 피아노 같은 소리를 여러 개 겹치고 소리마다 음량을 정해요. "비 오는 서재" 같은 장면을 누르면 한 번에 골라져요. 펫을 다시 켜도 듣던 소리가 이어져요.
- 아바타를 **끌면** 원하는 곳으로 옮겨요. 화면 맨 위까지 옮길 수 있어요. 위쪽에서 대화창을 열면 펫이 자리가 날 만큼 내려왔다가, 닫으면 제자리로 돌아가요. 가만두면 가끔 화면 아래를 산책해요.
- 아바타를 **우클릭**하면 메뉴가 떠요.
  - 문집 목록: 누르면 그 문집 대화창이 열려요. 안 읽은 수가 붙어요.
  - 문집 열기·참여, 이 문집 펫에서 빼기
  - 캐릭터 바꾸기
  - 펫 끄기

## 알림

| 언제 | 펫이 하는 일 |
| --- | --- |
| 누가 말하면 | 말풍선이 9초 떠요. 안 읽은 수가 아바타에 붙어요 |
| 누가 `@내 닉네임`이나 `@모두`로 부르면 | 펫이 크게 뛰고, 말풍선이 누를 때까지 남아요. 숫자 앞에 `@`가 붙어요 |
| 누가 독후감을 내면 | "내 글을 내면 N편이 열려요" (이미 냈으면 "지금 읽을 수 있어요") |
| 내 글에 답글이 달리면 | 답글 앞부분을 보여 줘요. 누를 때까지 남아요 |
| 마감이 오늘이나 내일인데 아직 안 냈으면 | 하루 한 번, 낮(9시~23시)에만 재촉해요 |
| 모집을 마감하면 | "이제 한 권으로 엮을 차례예요" |

소식 말풍선을 누르면 그 화면이 브라우저로 열려요. 안 읽은 수는 서버가 기억해서 펫을 다시 켜도 이어져요.

## 업데이트

펫은 켤 때와 30분마다 새 버전을 찾아요. 찾으면 뒤에서 받으면서 진행률을 보여 주고, 다 받으면 **지금 다시 켜기** 말풍선을 띄워요. 누르지 않으면 다음에 끌 때 바뀌어요. 바뀐 뒤에는 "새 버전으로 바뀌었어요"가 떠요.

바로 받고 싶으면 메뉴 막대 아이콘의 **업데이트 확인**을 누르거나 껐다 켜요.

사이트(서버)가 새로 배포되면 펫 화면은 스스로 새로 고쳐요. 쓰던 말이 있거나 메뉴를 열어 두었으면 끝날 때까지 기다려요. 그래서 껐다 켤 일은 앱 자체가 바뀔 때뿐이에요.

```bash
pkill -x BookReportPet; sleep 2; open /Applications/BookReportPet.app
```

## 메뉴 막대 아이콘

맥은 위쪽 메뉴 막대, 윈도우는 작업 표시줄 오른쪽에 있어요. 펫 다시 띄우기, 산책, 제자리로, 대화창·모임방 열기, 문집 열기·참여, 개인 링크로 연결, 업데이트 확인·기록 보기, 로그인할 때 열기, 펫 끄기를 할 수 있어요.

펫이 켜져 있는 동안은 모임방에서 나도 "들어와 있는 사람"으로 보여요.

## 만들기

```bash
cd desktop
npm ci
npm start                          # 개발 실행
PET_BASE_URL=http://localhost:8080 npm start   # 로컬 서버에 붙이기
npm run dist                       # 설치 파일 만들기
```

`main` 브랜치에 `desktop/`이 바뀌어 올라가면 GitHub Actions가 맥·윈도우 설치 파일을 만들어 릴리스에 올려요.
