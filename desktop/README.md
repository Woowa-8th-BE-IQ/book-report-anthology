# 남의 독후감 펫

모임방의 내 아바타가 바탕화면 위에 떠 있어요. 모임방에 새 말이 오면 머리 위로 말풍선이 떠요.

## 받기

[릴리스](https://github.com/Woowa-8th-BE-IQ/book-report-anthology/releases)에서 `pet-v…`를 열고 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 파일 |
| --- | --- |
| 맥 (M1 이후) | `book-report-pet-…-mac-arm64.dmg` |
| 맥 (인텔) | `book-report-pet-…-mac-x64.dmg` |
| 윈도우 | `book-report-pet-…-win-x64.exe` |

## 처음 실행할 때

서명하지 않은 앱이라 처음 한 번은 경고가 떠요.

- **맥**: dmg를 열어 앱을 응용 프로그램 폴더로 옮겨요. 그다음 앱을 **우클릭 → 열기 → 열기**를 눌러요. 그래도 막히면 터미널에서 `xattr -cr "/Applications/남의 독후감 펫.app"`를 한 번 실행해요.
- **윈도우**: "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.

앱이 열리면 문집 화면 아래 **내 개인 링크**를 붙여 넣어요. 그러면 연결돼요.

## 쓰는 법

- 아바타를 **누르면** 작은 대화창이 열려요. 바로 답장할 수 있어요.
- 아바타를 **끌면** 원하는 곳으로 옮겨요.
- 가만두면 가끔 화면 아래를 산책해요.
- 메뉴 막대(윈도우는 작업 표시줄 오른쪽)의 아이콘에서 다음을 할 수 있어요.
  - 숨기기
  - 산책 끄기
  - 제자리로
  - 모임방 열기
  - 링크 바꾸기
  - 로그인할 때 열기
  - 끝내기

펫이 켜져 있는 동안은 모임방에서 나도 "들어와 있는 사람"으로 보여요.

## 만들기

```bash
cd desktop
npm ci
npm start                          # 개발 실행
PET_BASE_URL=http://localhost:8080 npm start   # 로컬 서버에 붙이기
npm run dist                       # 설치 파일 만들기
```

`main` 브랜치에 `desktop/`이 바뀌어 올라가면 GitHub Actions가 맥·윈도우 설치 파일을 만들어 릴리스에 올려요.
